|| RU ||
Скрипт работате как аюграм а точнее его функцыя видеть удалённые саобщения.
Описание:
  Селф-бот, предназначенный для мониторинга и записи всех изменений и удалений сообщений в реальном времени. 
  Когда сообщение редактируется или удаляется на сервере Telegram или в личной переписке, бот сохраняет исходное содержание, и соответствующую метаданные (автор, канал).
  Все обнаруженные изменения выводятся в консоль для удобного отслеживания.

|| EN ||  
The script works like AyoGram, specifically its feature to see deleted messages.  

Description:  
  A self-bot designed to monitor and log all message edits and deletions in real time.  
  When a message is edited or deleted on a Telegram server or in a private chat, the bot saves the original content and relevant metadata (author, chat).  
  All detected changes are displayed in the console for easy tracking.
