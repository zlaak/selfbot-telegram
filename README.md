### **English Version (EN)**  
The script works like **AyuGram**, specifically its feature to view deleted messages.  

**Description:**  
  A self-bot designed to monitor and log all message edits and deletions in real time.  
  When a message is edited or deleted on a Telegram server or in a private chat, the bot saves the original content along with relevant metadata (author, chat).  
  All detected changes are displayed in the console for easy tracking.  

**Help:**  
**How to get `api_id` and `api_hash` for the script:**  
  1. Go to your account here: [https://my.telegram.org/auth](https://my.telegram.org/auth) (official link).  
  2. Select **API development tools**.  
  3. The first two values will be your `api_id` and `api_hash`.  

### **Русская Версия (RU)**  
Скрипт работает как **AyuGram**, а точнее, как его функция просмотра удалённых сообщений.  

**Описание:**  
Селф-бот, предназначенный для мониторинга и записи всех изменений и удалений сообщений в реальном времени.  
Когда сообщение редактируется или удаляется в Telegram (на сервере или в личном чате), бот сохраняет исходный текст и соответствующие метаданные (автор, чат).  
Все обнаруженные изменения выводятся в консоль для удобного отслеживания.  

**Помощь:**  
**Как получить `api_id` и `api_hash` для скрипта:**  
  1. Перейдите в свой аккаунт здесь: [https://my.telegram.org/auth](https://my.telegram.org/auth) (официальная ссылка).  
  2. Выберите пункт **API development tools**.  
  3. Первые два значения будут вашими `api_id` и `api_hash`.
